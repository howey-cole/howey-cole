## Professional work

My work at Dick's Sporting Goods uses proprietary data and code, so none of it is published here. In summary:

- **Experimentation:** A/B tests of operational processes across the store fleet, with minimum detectable effect simulation before launch and fixed-effects regression for analysis.
- **Causal and root-cause modeling:** generalized linear models that identify when and why an operational or ecommerce metric shifted, where a controlled test was not possible.
- **Machine learning:** store segmentation with principal component analysis and K-means clustering, replacing manual store classification.
- **Metric and data governance:** new operational metrics, event instrumentation and an enterprise inventory data model on Azure Databricks.
- **AI-enabled analytics:** business logic and validation of LLM-generated SQL for Databricks Genie Spaces.

More detail is on my [website](https://www.colehowey.com/).
